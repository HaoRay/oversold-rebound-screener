# 超卖反弹候选池筛选器

一个「特定日子才生效」的全市场超卖反弹候选池工具：先判断当天是否为「普跌 + 超卖密集」的信号日，若是，再从当日超卖股中筛出**回撤相对深**的一批作为候选池。

**定位**：观察级提示器，不是自动交易系统，不构成收益承诺。请先读完「已知边界」再使用。

---

## 一、环境准备

需要 Python 3.9+，依赖三个公开库：

```bash
pip install numpy pandas akshare
```

## 二、拉取数据

```bash
python fetch_data.py --start 20100101 --end 20260901 --out ./data
```

遍历主板全部个股，逐只下载前复权日线并写入 `./data/`（每股一个 CSV，已存在的会跳过，可中断续跑）。

输出格式约定——每个 CSV 至少包含以下列：

```
date, open, high, low, close
```

脚本会对 `date` 做字符串比较，格式统一为 `YYYY-MM-DD`。

> 数据源为公开接口（AKShare 转发），存在限流与被阻断的可能。脚本内置重试与断点续传；若中途大量失败，可重跑补齐。

## 三、扫描当日

```bash
python scripts/scan.py                       # 取数据中最后一个交易日
python scripts/scan.py --date 2026-09-18     # 指定日期
python scripts/scan.py --date 2026-03-23 --top 30
python scripts/scan.py --date 2026-03-23 --all-cand
```

输出三部分：① 信号日判定（两个条件逐条对比实测值与阈值）；② 若为信号日，列出候选池；③ 强制披露。

实测扫描全市场主板约 15 秒。

---

## 四、判定规则

两个条件必须**同时满足**：

| 条件 | 定义 | 示例阈值 |
|---|---|---|
| **C1 普跌** | 当日**上涨家数占比** ≤ `Q1(Y)` | 0.3441 |
| **C2 超卖密集** | 当日**超卖股家数** ≥ `icq2(Y)`（超卖 = `RSI6 ≤ 20`） | 76 家 |

股票池为**主板**（代码前缀 600/601/603/605/000/001/002/003），上涨家数占比按主板全体计算。池子按代码前缀构建，数据源不含股票名称字段，因此**未按名称做额外剔除**；如需限定特定类型标的，请在拉取阶段自行按名称过滤。

实测信号频率：**约 80% 的交易日不出信号**（平均每 5 个交易日里大约 1 天）。不要为了让每天都出票而放宽阈值。

## 五、选股规则

若当天是信号日：

1. 取当日全部超卖股（`RSI6 ≤ 20`）；
2. 对每只计算 `dd60 = 收盘价 / 近 60 个交易日最高收盘价 − 1`（负值，越小表示回撤越深）；
3. 在**当日超卖股内部**计算 `dd60` 的百分位；
4. **候选池 = 百分位 ≤ 1/3 的那批**（回撤最深的一批）。

**为什么取回撤深的一批**：在超卖股内部，回撤深的一档 14 日收益比回撤浅的一档高 0.52~0.84pp，且跨超卖定义、跨股票池、跨持有期 **4/4 方向**一致。

机制上：市场整体普跌时，回撤最深的标的多为「被错杀」，反弹弹性最大；回撤浅的多是抗跌品种，反弹空间反而有限。

## 六、买卖与仓位

| 项 | 规则 |
|---|---|
| 买入 | 信号日 t 的**次日开盘** |
| 放弃买入 | 若次日开盘 ≥ 信号日收盘 × 1.098（一字涨停无法成交）则放弃该票 |
| 卖出 | 第 14 个交易日（t+14）**收盘** |
| 卖出受阻 | 若遇一字跌停无法卖出，顺延至下一可交易日（实测概率 0.057%） |
| 仓位 | 每日候选约 135 只 → **随机取 3~10 只等权**即可（与全买等效，实测最大差 0.020pp） |
| 成本 | 按 **0.25% 双边**计（所有统计数字均已扣除） |

### 持有期为什么定 14 个交易日

| 持有 | 胜率 | 日均净收益 | 相对超额 | 逐年相对超额为正 |
|---|---|---|---|---|
| 5 日 | 57.10% | −0.147% | +0.064%（不显著） | — |
| 7 日 | 58.47% | +0.348% | +0.293% | 仅 4/7 |
| 10 日 | 57.41% | +0.724% | +0.563% | — |
| **14 日** | 57.44% | **+1.160%** | **+0.857%** | **7/7** |
| 20 日 | 59.48% | +1.666% | +1.006% | — |

- **胜率几乎不随持有期变化（57.1% ~ 59.5%）**，说明收益来自「选到哪类票」而非「赚多久」；
- **缩短到 7 日会让逐年相对超额从 7/7 掉到 4/7**，单位时间效率也更低（+0.050% vs +0.083%），故不采用。

## 七、阈值维护（必须做）

每年年初用**截至上年末**的数据重估一次：

```
Q1(Y)   = 上涨家数占比 在 [2010, Y−1] 全部交易日的 1/3 分位
icq2(Y) = 当日超卖股家数 在 [2010, Y−1] 全部交易日的 2/3 分位
```

**为什么必须重估**：`icq2` 是**绝对家数**，随上市家数增长而单调上移（实测 2020 年 62 → 2025 年 78）。把阈值写死会导致策略在未来自动失效。

`config.json` 的 `thresholds_used` 已存入各年实际使用值，新增年份需自行补算。

## 八、验证与稳健性

| 检验项 | 结果 |
|---|---|
| 分离「时机」与「选股」 | 超卖单独出现无超额；**「超卖 × 普跌」同时出现才有**（+0.430%，CI [+0.201, +0.683]） |
| 叠加回撤分档 | 再叠加「回撤最深 1/3」→ 日内超额 **+0.857%**（CI [+0.532, +1.194]），逐年 6/7 年为正 |
| 跨口径复制 | 「回撤深 − 回撤浅」在 **4/4** 方向（换超卖定义 / 换股票池 / 换持有期）显著为正 |
| 重叠样本 | 用「首次进入」去重到 33% 后，效应反而上升（+0.923%），说明不是重叠样本造成的 |
| 资金可行性 | 每天随机买 3~50 只与全买等效（最大差 0.020pp） |
| 成本敏感性 | 成本从 0.25% 提到 0.60% 仍为正 |
| 生存者偏差 | 约 −0.08pp（前提：不交易退市整理期股票） |
| 逐年滚动检验 | 阈值改为「只用当年以前的信息」后结果几乎不变（+1.083% → +1.160%），说明阈值不是拟合出来的 |
| 实操可执行性 | 卖出日一字跌停占比 0.057%；顺延后仅 −0.001pp |

本项目也检验过若干**未通过**的替代方案（例如用指数替代个股、只用超卖不叠加普跌、叠加更多指标），可参考 `backtest.py` 自行复现。

> **关于复现**：上表为本项目在原研究区间（2010–2026，主板口径自洽）上的结果。`backtest.py` 是独立实现，在同一区间上**结论方向可复现**（相对超额为正、逐年多数为正），具体数值会因数据区间、股票池与阈值口径有小幅差异——请以自己跑出的结果为准。

## 九、已知边界

1. **绝对收益不稳定**：策略逐年绝对净收益只有 4/7 年为正，某一年为 −1.48%（同期对照 −2.22%）。它的强项是**相对超额**——对比同一天、同一环境下的非超卖股，7/7 年为正，中位 +0.822%。**准确表述是「比同期其他票好」，不是「能赚钱」**。禁止表述为稳赚 / 正期望 / 推荐买入 / 必涨。
2. **信号稀少**：约 **80% 的交易日无信号**。
3. **适用边界**：
   - 假设**不交易退市整理期**股票；
   - 持有期为 **14 个交易日**，勿与其他持有期策略混用同一套仓位管理；
   - 未建模跌停板排队成交概率（只做「可卖 / 不可卖」二元判定）；
   - **未做跨市场样本外验证**。
4. **已知口径问题**：`Q1 / icq2` 阈值取自全市场分位，而 `scan.py` 的实测量只统计主板池。主板现占全市场约 61%，极端行情下（成长板块涨、主板跌）可能多报信号日。修复需重估阈值并回放验证，**修改前请同时留意两口径数值**。

## 十、独立回测

```bash
python backtest.py                       # 用 ./data 全部数据
python backtest.py --hold 14 --cost 0.25
python backtest.py --limit 300           # 快速试跑（只读前 300 只）
```

回测逻辑与实盘一致：自动计算逐日市场宽度、年度滚动阈值、超卖股与回撤分位，按「信号日 → 次日开盘买入 → 第 14 交易日收盘卖出」计收益，并与**同日非超卖股**对照，输出逐年与全期结果 + 日聚类 95% 置信区间。

**注意**：回测需要**全市场主板数据**才有意义——「上涨家数占比」与「超卖股家数」都是全市场统计量。若只放入部分股票，判定结果会与真实情况不同。
